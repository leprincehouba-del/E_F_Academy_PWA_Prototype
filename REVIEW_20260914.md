# Release review — 2026-09-15

User authorized review, fixes and production publication. No additional merge approval is needed after the database prerequisite succeeds.

## Scope and review fixes

- Walaa can choose a different points reason for each student; the existing reason buckets and authorized queue RPC remain in use.
- Save is locked before the asynchronous session check to prevent two submissions from repeated clicks. Controls remain locked during submission.
- Unlabelled drafts survive list refresh, global default assignment preserves their values, and changing a student's reason cannot overwrite another saved draft.
- All drafts, including hidden reason buckets, are validated. Failed sends retain their values and successful sends are removed.
- Session-access results are scoped to request/group/date; a delayed result cannot open another group's controls.
- Owner package correction keeps consumed sessions, updates the existing receipt and retains an audit record. Recent receipt history is reloaded from the backend after a correction, and a refresh failure is distinguished from correction failure.
- New purchases are blocked when arrears exist by an INSERT trigger covering both purchase RPCs. Existing attendance/package consumption is not blocked by that trigger.
- Package purchase confirmation shows the student, sessions and amount; an on-screen explanation shows why arrears block a purchase.
